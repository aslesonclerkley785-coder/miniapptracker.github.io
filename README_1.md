# Операционка недели — Telegram-бот

Порт HTML-трекера «Операционка недели» в бота на **aiogram v3 + SQLAlchemy async (SQLite) + APScheduler**. Все данные — по ISO-неделям, «скелет» правится прямо из бота через админку.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate   # опц.
pip install -r requirements.txt
cp .env.example .env         # впиши BOT_TOKEN и ADMIN_IDS
python bot.py
```

`.env`:
```
BOT_TOKEN=...            # от @BotFather
ADMIN_IDS=111111111      # твой Telegram id (через запятую можно несколько)
DB_PATH=operatsionka.db
```

`/start` — трекер текущей недели. Всё остальное — кнопками.

## Что есть в трекере (недельные данные)

- **Воронка** — отклики → ответы → заказы; кнопки ±1/±5 и ручной ввод; конверсии с подсветкой ниже порога; недельная цель = норма × множитель.
- **Деньги** — по источникам, с итогом; сумма вводится числом.
- **Дисциплина** — сетка привычек × 7 дней (тап по дню = отметка). У «строки-квоты» считается серия дней подряд (как в оригинале — серию жалко рвать).
- **Топ-3 на завтра** — три слота, перезаписываются.
- **Воскресный обзор** — свободный текст.
- **Каркас дня** — просмотр шаблонов дней со слотами.
- Навигация: ← пред. / сегодня / след. → (каждая неделя изолирована).

## Что правится из админки (скелет) — раздел «⚙️ Админка»

Доступен только id из `ADMIN_IDS`.

| Раздел | Что можно |
|---|---|
| **🗓 Каркас дня** | добавлять/удалять/переименовывать типы дней; менять тег и вид (gym/cardio); внутри дня — добавлять/править/удалять/переставлять слоты, задавать время, текст и прайм-блок (★) |
| **✅ Привычки** | добавлять/переименовывать/удалять/переставлять строки сетки; назначать «строку-квоту» (🔥) — она всегда одна |
| **💰 Источники денег** | добавлять/переименовывать/удалять/переставлять; скрывать источник (👁/🚫) |
| **📊 Названия воронки** | переименовывать подписи трёх стадий (сама структура из 3 стадий фиксирована — на ней держатся конверсии) |
| **⚙️ Настройки** | норма/день по умолчанию, множитель недельной цели, пороги конверсий, тезис в шапке, напоминания (вкл/выкл + время + часовой пояс) |

Дефолты при первом запуске засеваются из исходного HTML (те же дни, слоты, привычки, источники).

## Напоминания

Опциональные утреннее и вечернее сообщения админам (APScheduler). Включаются и настраиваются в «⚙️ Настройки»; изменение времени/пояса пересобирает расписание на лету.

## Структура

```
bot.py               точка входа: БД, засев, роутеры, планировщик, polling
config.py            pydantic-settings (ADMIN_IDS парсится вручную — обход NoDecode)
db.py                модели + движок/сессия (async)
seed.py              дефолтный конфиг из исходного HTML
services.py          ISO-недели, доступ к данным/конфигу, серия, тексты экранов
keyboards.py         callback-фабрики и инлайн-клавиатуры
states.py            FSM-состояния ввода
handlers_tracker.py  хендлеры трекера
handlers_admin.py    хендлеры админки
reminders.py         напоминания
```

## Заметки

- SQLite + `expire_on_commit=False`. Для нагрузки на несколько пользователей норм; при желании — Postgres (поменять URL и драйвер).
- Выбранная неделя (offset) хранится в памяти процесса на пользователя и сбрасывается на текущую при `/start` — переживать рестарты ей не нужно, «текущая» всегда считается от даты.
- Порядок роутеров в `bot.py` важен: трекер-роутер подключается раньше админского (см. фильтры `Nav`).
